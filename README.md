# Folk House Capture — One Page Website

A Vercel-ready static landing page for Folk House Capture.

## Quick deploy
1. Create a GitHub repository.
2. Upload everything in this folder.
3. Go to https://vercel.com
4. Add New → Project → select the GitHub repository.
5. Framework Preset: Other / Static.
6. Click Deploy.

## First things to replace
- `assets/folk-house-logo.jpg` — replace with the final logo file.
- The Unsplash image URLs in `styles.css` — replace with your own photos/videos.
- Sample project names in `index.html`.
- Contact/social links in `index.html`.
